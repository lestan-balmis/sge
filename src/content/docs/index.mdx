## El módulo en dos frases

Primero aprendemos **qué hace un ERP** usando Axelor.
Luego **construimos uno desde cero** con Spring Boot.

## Las dos fases

| Fase | Herramienta | Objetivo |
|---|---|---|---|
| Referencia funcional | **Axelor** | Entender qué hace un ERP profesional |
| Implementación | **Spring Boot** | Construir el ERP Balmis desde cero |
