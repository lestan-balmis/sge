## El módulo en dos frases

Primero aprendemos **qué hace un ERP** usando Axelor (14h).
Luego **construimos uno desde cero** con Spring Boot (54h).

## Las dos fases

| Fase | Herramienta | Horas | Objetivo |
|---|---|---|---|
| Referencia funcional | **Axelor** | 14h | Entender qué hace un ERP profesional |
| Implementación | **Spring Boot** | 54h | Construir el ERP Balmis desde cero |
